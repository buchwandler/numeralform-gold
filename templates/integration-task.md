# Numeralform Gold mechanical integration

Integration is deterministic and mechanical. Run batch preflight before writing. Only adjudication decisions marked `accept` may create canonical records. Preserve the original semantic case, source observations, stable record identity, and adjudicated oracle. Excluded and unresolved cases are retained in batch reports or retry artifacts and are never materialized into Gold.

Use dry-run first, then use the explicit write flag. Do not manually edit multilingual JSONL or reinterpret reviewer decisions.
